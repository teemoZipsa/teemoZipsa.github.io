💡 Comprehensive Guide to Image Formatting

1. Which image format should I use?

Accepted inputs are JPG, PNG, WebP, GIF, BMP, and SVG. Available outputs are JPG, PNG, and WebP only.

  • JPG (JPEG): Extremely common. Best for standard photographs. It uses lossy compression, resulting in significantly smaller file sizes. It does not support transparent backgrounds.
  • PNG: Useful for graphics, screenshots, and images requiring transparency. Output encoding is lossless, though canvas re-encoding can remove metadata from the source file.
  • WebP: A web-oriented format that supports photos and transparency. It may be smaller than JPG or PNG, but conversion does not guarantee a smaller file.
2. Does converting image formats reduce file size?

Sometimes. JPG and WebP use the selected Quality setting and may reduce a large source, while PNG can become larger. The result panel reports the actual before-and-after size; no format guarantees a fixed saving.

3. Are GIF animation and SVG vectors preserved?

No. The browser draws the source onto a canvas before encoding it. An animated GIF becomes one still frame, and SVG is rasterized at its displayed pixel dimensions, so scalable vector information is not preserved. A visible warning appears when either source type is selected.

4. Is my privacy protected during conversion?

The selected image is read and converted in your current browser and is not uploaded for conversion. On a shared device, remember to manage the downloaded result and browser history yourself.
