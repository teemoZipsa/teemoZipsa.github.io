💡 Comprehensive Guide to QR Code Generation

1. How to Use
  1. Enter the URL, text, or contact information you want in the input box.
  2. Choose a module size and error-correction level. M is a good default for general use.
  3. The QR code is generated in real time with a four-module white quiet zone.
  4. Download or copy the generated PNG, then test it with a real phone before distribution.
2. What is the minimum print size for a QR code?

There is no single minimum that works for every QR code. More data produces more modules, so each module becomes smaller at the same print size. Keep the four-module quiet zone and test the final print at its real viewing distance with representative phones. For a small handout, starting around 2–3 cm and testing before distribution is a practical baseline, not a guarantee.

3. What if the QR code won't scan?

Common causes include a print that is too small, weak contrast, blur or distortion, a cropped white border, and too much data. You can choose L (about 7%), M (about 15%), Q (about 25%), or H (about 30%) error correction. Those percentages are general damage-recovery approximations; real scan performance also depends on the camera, print quality, and type of damage.

4. Can I put long texts or special URLs in the QR code?

Yes, within QR capacity. The more data you include, and the higher the selected error correction, the more complex the pattern can become. Capacity also varies by character encoding, so there is no single limit that applies to every input. Use short, stable URLs whenever possible for the best scanning experience.

5. Why does the downloaded image include a white border?

The PNG includes a four-module quiet zone on every side inside the image canvas. This clear border helps scanners distinguish the QR code from its surroundings. Keep it intact when cropping, printing, or placing the image over another background.
