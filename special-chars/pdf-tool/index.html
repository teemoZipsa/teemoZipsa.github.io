💡 PDF 도구 사용 가이드와 자주 묻는 질문

민감한 계약서나 증명서 PDF를 올려도 안전한가요?

선택한 PDF와 이미지는 서버로 업로드되지 않고, 사용 중인 브라우저의 메모리 안에서만 처리됩니다.

파일을 서버에 올려 처리하는 온라인 PDF 서비스는 문서가 외부 서버를 거치므로, 해당 서비스의 보관·삭제 정책을 따로 확인해야 합니다. 이 도구는 pdf-lib로 PDF 구조를 편집하고 PDF.js로 미리보기와 이미지 변환을 합니다. 두 엔진과 렌더링 워커는 이 사이트에 고정 버전으로 포함되어 있어 외부 CDN에 연결하지 않으며, 페이지를 한 번 불러온 뒤에는 네트워크가 끊겨도 현재 탭에서 작업할 수 있습니다.

한 번 불러온 PDF는 다른 탭으로 옮겨도 다시 고를 필요 없이 이어서 쓸 수 있습니다. 불러온 파일은 탭을 닫거나 새로고침하거나 “모두 비우기”를 누르면 메모리에서 사라집니다. 다만 브라우저 확장 프로그램이나 기기 자체의 보안까지 보장할 수는 없으므로, 매우 민감한 원본은 백업해 두고 신뢰할 수 있는 기기에서 사용하세요.

사용 라이브러리: pdf-lib 1.17.1 (MIT), PDF.js 4.2.67 (Apache-2.0). PDF는 파일당 40MB·한 번에 20개/80MB·문서당 200페이지까지, 이미지는 파일당 20MB·8,000px/2,400만 픽셀까지 처리합니다. 버전·라이선스 정보

각 기능은 무엇을 하나요?
  • 📎 합치기: 여러 PDF를 목록 순서대로 하나로 합칩니다. 끌어 놓기나 ↑·↓ 버튼으로 순서를 바꿀 수 있고, 결과 파일은 첫 번째 파일 이름 뒤에 _merged가 붙습니다.
  • ✂️ 나누기: 1-3, 5, 7~10처럼 입력한 페이지를 새 PDF로 뽑습니다. 선택한 페이지를 한 파일로 저장하거나, 쉼표로 나눈 범위마다 또는 한 장씩 따로 저장할 수 있으며, 결과가 여러 개면 ZIP 파일 하나로 내려받습니다.
  • 🔄 회전: 페이지마다 또는 전체를 90° 단위로 돌립니다. 페이지의 회전 값만 바꾸므로 글자 선택·검색과 화질은 그대로입니다.
  • ↕️ 순서: 썸네일을 끌어 놓거나 이전·다음 버튼, “역순으로” 버튼으로 페이지 순서를 바꿉니다. 거꾸로 스캔된 문서를 바로잡을 때 편리합니다.
  • 🗑️ 페이지 삭제: 입력한 페이지를 뺀 새 PDF를 만듭니다. 모든 페이지를 지울 수는 없습니다. 여러 페이지가 같은 글꼴·이미지를 공유하는 문서는 페이지를 지워도 용량이 크게 줄지 않을 수 있습니다.
  • 💧 워터마크: “대외비”, “DRAFT” 같은 한글·영문 문구를 모든 페이지 정가운데에 원하는 방향·색·불투명도로 넣습니다. 미리보기와 결과 파일은 같은 계산으로 그려집니다.
  • 🔢 페이지 번호: 각 페이지 아래쪽에 “1 / 12” 같은 번호를 넣습니다. 옆으로 회전된 페이지도 화면에 보이는 방향을 기준으로 아래쪽에 들어갑니다.
  • 📄 빈 페이지: 지정한 페이지 뒤(0이면 맨 앞)에 빈 페이지를 넣습니다. 크기와 방향은 바로 앞 페이지를 따르므로 양면 인쇄 순서를 맞출 때 쓸 수 있습니다.
  • 📝 문서 정보: PDF 속성에 보이는 제목·작성자·주제·키워드를 고치거나 비웁니다.
  • 🖼️ 이미지→PDF: JPG·PNG·WebP를 한 장에 한 페이지씩 PDF로 만듭니다. 기본값은 A4 용지에 이미지 방향(가로·세로)을 맞춰 여백 안에 가운데 배치하는 방식이며, 여백 없이 이미지 비율대로 페이지를 만들 수도 있습니다. 스마트폰 사진의 회전 정보는 브라우저가 적용한 방향대로 반영됩니다.
  • 📸 PDF→이미지: 선택한 페이지를 JPG나 PNG로 저장합니다. 150dpi는 문서 첨부용, 300dpi는 인쇄용으로 적당합니다.
페이지 범위는 어떻게 입력하나요?

페이지 번호는 쉼표로 구분하고, 연속된 범위는 하이픈(-)이나 물결표(~)로 적습니다. 예를 들어 1-3, 5, 7~10은 1·2·3·5·7·8·9·10페이지를 뜻합니다. 8-처럼 끝 번호를 비우면 8페이지부터 마지막 페이지까지입니다.

문서에 없는 페이지 번호, 2.5 같은 소수, 10-7처럼 거꾸로 적은 범위는 입력칸 아래에 이유를 표시하고 처리하지 않습니다. 나누기에서 “PDF 하나로” 저장하면 입력 순서와 관계없이 원본 순서대로 담기고, 같은 페이지를 두 번 적어도 한 번만 들어갑니다. 원하는 순서로 재배치하려면 “순서” 기능을 사용하세요.

합치거나 나눌 때 무엇이 유지되고 무엇이 사라지나요?

합치기·나누기·회전·순서·삭제는 페이지를 이미지로 바꾸지 않고 원래 페이지의 글자·벡터 그림·이미지를 그대로 옮기므로, 일반적으로 글자 선택·검색과 화질이 유지됩니다.

다만 새 PDF로 다시 저장하는 과정에서 책갈피(목차), 문서 안 링크 일부, 입력 양식(폼) 필드, 전자서명은 유지되지 않거나 무효가 될 수 있습니다. 전자서명된 문서는 내용을 조금만 바꿔도 서명 검증이 실패합니다. 또 저장할 때 PDF 속성의 생성 프로그램(Producer) 정보가 pdf-lib로 바뀝니다. 제출용 문서라면 원본을 따로 보관하고 결과 파일을 열어 확인하세요.

암호가 걸린 PDF도 편집할 수 있나요?

열기 암호가 있는 PDF는 처리할 수 없습니다. 암호를 알고 있다면 PDF 뷰어에서 연 뒤 암호 없이 저장한 사본을 사용하세요.

열기 암호 없이 편집·복사 권한만 제한된 PDF(은행·공공기관 발급 문서에 흔합니다)는 회전, 페이지 삭제, 빈 페이지 추가, PDF→이미지만 지원합니다. 이 경우 결과를 내려받기 전에 원본과 내용이 같은지 자동으로 비교하고, 다르면 파일을 만들지 않습니다. 합치기·나누기·워터마크처럼 내용을 새로 쓰거나 옮기는 작업은 보안 설정을 해제해야 하므로 지원하지 않습니다.

워터마크를 넣으면 복사나 캡처를 막을 수 있나요?

아닙니다. 워터마크는 문서의 용도나 상태를 알리는 표식일 뿐 복사·인쇄·화면 캡처를 기술적으로 막지 않습니다. 이 도구의 워터마크는 반투명 이미지로 들어가므로 PDF 편집 프로그램으로 지울 수도 있습니다. 외부에 보내는 문서의 유출 경로를 확인하려는 목적이라면 받는 사람이나 날짜를 문구에 함께 넣는 방법이 흔히 쓰입니다.
