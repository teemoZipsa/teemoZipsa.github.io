💡 일상 퀘스트 가이드

퀘스트·게임·상점 연결 방식
퀘스트를 고르면 완료 조건과 예상 보상이 타이머에 표시됩니다. 시간이 끝난 뒤 조건을 확인하면 냥과 경험치가 게임 탭에 반영됩니다. 모은 냥은 상점에서 아지트를 꾸미거나 다음 퀘스트의 보너스 아이템을 준비하는 데 사용할 수 있습니다.
타이머 사용법
시, 분, 초를 직접 입력하거나 숫자 버튼(예: 5분, 1시간)을 눌러 시간을 빠르게 설정하세요. 재생 버튼(▶)을 누르면 카운트다운이 시작되며, 시간이 다 되면 자동으로 알림음이 울립니다.
퀘스트 완료 확인
타이머가 끝나면 선택한 퀘스트의 완료 조건이 다시 나타납니다. 실제로 끝낸 항목을 체크하면 보상이 기록됩니다. 퀘스트와 게임 기록은 현재 브라우저에 저장됩니다.
스톱워치 사용법
스톱워치 탭을 선택한 뒤 재생 버튼(▶)을 누르면 시간이 측정됩니다. 실행 중 랩 버튼(🏁)을 눌러 구간 기록을 남길 수 있습니다. 측정이 끝나면 정지 버튼(■)을 눌러주세요.
단축키
  • 스페이스바: 시작 / 정지
  • R: 초기화(리셋)
  • L: 랩 기록 (스톱워치 모드)
언제 어떤 모드를 쓰면 좋나요?
타이머는 정해진 시간이 끝났는지 확인해야 하는 작업에 맞습니다. 요리, 휴식 시간, 운동 세트, 25분 집중 작업처럼 종료 알림이 필요한 경우에 사용하세요. 스톱워치는 시간이 얼마나 걸렸는지 측정하는 용도입니다. 발표 리허설, 달리기 기록, 작업 소요 시간 측정, 반복 업무의 평균 시간을 확인할 때 적합합니다.
집중 작업에 쓰는 기준
짧은 집중에는 10~15분, 일반적인 포모도로에는 25분, 긴 문서 작업이나 코딩에는 45~60분을 먼저 시도해 보세요. 너무 긴 시간을 한 번에 잡으면 중간에 흐름이 끊기기 쉽습니다. 반복 업무는 스톱워치 랩 기록으로 구간을 나눈 뒤, 실제로 오래 걸리는 단계를 찾아 개선하는 방식이 좋습니다.
알림이 들리지 않을 때 확인할 점
브라우저 타이머는 실제 종료 시각을 기준으로 남은 시간을 보정하지만, 페이지가 완전히 정지된 동안에는 소리를 낼 수 없습니다. 탭으로 돌아오면 종료 상태를 즉시 반영하고 알림음을 시도합니다. 모바일에서 화면을 끄거나 배터리 절약 모드가 켜져 있으면 브라우저가 실행을 제한할 수 있으므로, 중요한 시험·조리·약 복용 알림은 휴대폰 기본 알람도 같이 설정하세요.
기록을 남기는 작업에 쓰는 방법
스톱워치 랩은 전체 시간 안에서 구간별 소요 시간을 분리할 때 유용합니다. 발표 연습이라면 도입, 본론, 마무리 구간마다 랩을 누르고, 운동이라면 세트마다 랩을 남기세요. 기록을 비교하면 매번 늦어지는 구간이나 시간을 줄일 수 있는 단계를 쉽게 찾을 수 있습니다.
공부, 운동, 요리에서 쓰는 예시
공부할 때는 25분 집중과 5분 휴식을 반복하거나, 암기 과목처럼 짧게 끊는 작업은 10분 단위로 나눠 진행할 수 있습니다. 운동에서는 세트 사이 휴식 시간을 60~90초로 맞추거나 인터벌 운동의 운동 시간과 휴식 시간을 번갈아 확인하는 데 쓸 수 있습니다. 요리에서는 삶기, 굽기, 뜸 들이기처럼 단계별 시간이 다를 때 각각 타이머를 다시 설정해 과조리를 줄이는 방식으로 활용하면 좋습니다.
