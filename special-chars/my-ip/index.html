🤔 내 IP 주소 확인 가이드 & Q&A
IP (Internet Protocol) 주소란 무엇인가요?
네트워크에서 데이터를 주고받기 위해 스마트폰, PC 같은 통신 기기에 부여되는 논리적 주소입니다. 인터넷의 '우편 주소'와 같은 역할을 합니다. 공유기나 회사 내부망 안에서만 쓰는 주소는 사설 IP, 그 네트워크가 인터넷으로 나갈 때 바깥에서 보이는 주소는 공인 IP(Public IP)라고 부르며, 이 도구가 보여 주는 것은 공인 IP입니다. 같은 공유기나 회사 네트워크를 쓰는 여러 기기는 보통 하나의 공인 IP를 함께 사용합니다.
IPv4와 IPv6의 차이점은 무엇인가요?
IPv4는 203.0.113.10처럼 0~255 사이 숫자 네 개를 점으로 이은 형식이고, IPv6는 2001:db8::1처럼 16진수 묶음을 콜론으로 이은 훨씬 긴 형식입니다(두 예시 모두 문서용으로 예약된 주소입니다). 192.168.x.x나 10.x.x.x는 공유기·사내망 안에서만 쓰는 사설 IPv4라 이 도구에는 나타나지 않습니다. 국내 LTE·5G와 일부 가정용 인터넷은 IPv4와 IPv6를 함께 쓰는 듀얼 스택이라 웹사이트가 IPv6 주소만 보는 경우가 많습니다. 그래서 이 도구는 IPv4 전용 조회와 IPv6 전용 조회를 동시에 실행해 두 주소를 모두 보여 줍니다.
방화벽 허용 요청에는 어떤 주소를 전달해야 하나요?
사내 방화벽, 클라우드 보안 그룹, 외부 협력사 시스템의 허용 목록은 대부분 IPv4 기준이므로 IPv4 주소를 먼저 전달합니다. 상대 시스템이 IPv6 접속도 받는다면 IPv6 주소를 함께 적어야 접속이 막히지 않습니다. 모바일 데이터나 일반 가정용 인터넷의 공인 IP는 재접속할 때마다 바뀔 수 있어, 고정 IP가 아니라면 허용 목록이 금방 무효가 될 수 있다는 점도 함께 알려 주세요. 'IT 문의용 정보 복사'를 누르면 IPv4·IPv6·브라우저·운영체제·확인 시각이 한 번에 복사되어 티켓이나 메신저에 바로 붙여넣을 수 있습니다.
접속 국가가 실제 위치와 다르게 나와요.
이 도구는 IP 주소 기준의 국가만 표시하며 시·군·동 단위 위치는 조회하지 않습니다. 국가 정보는 조회 서비스가 IP 주소 할당·위치 데이터베이스를 바탕으로 판단한 값이므로 GPS 위치와는 다릅니다. VPN, 해외 로밍, 회사 프록시, 브라우저의 IP 보호·비공개 릴레이 기능을 쓰면 실제로 있는 나라와 다른 국가가 표시될 수 있으며, 이는 정상적인 동작입니다.
브라우저와 운영체제는 어떻게 판별하나요?
브라우저가 보내는 사용자 에이전트(User-Agent) 문자열과, 지원되는 경우 User-Agent Client Hints 정보를 읽어 판별합니다. 네이버 웨일, 삼성 인터넷, Opera, Edge처럼 Chrome 기반 브라우저도 구분하고, 카카오톡·네이버 앱 안에서 열면 인앱 브라우저로 표시합니다. 최신 Chrome 계열은 개인정보 보호를 위해 일부 정보를 줄여 보내므로, Client Hints를 지원하지 않는 환경에서는 Windows 10과 11이 'Windows 10/11'로 함께 표시될 수 있습니다.

IT 지원과 방화벽 허용 요청에 쓰는 방법

업무 예시: 외부 시스템 접속이 차단됐을 때 'IT 문의용 정보 복사'로 공인 IP와 접속 환경을 한 번에 복사해 사내 IT 담당자에게 전달하거나, 원격 지원 전에 브라우저와 운영체제 정보를 함께 확인할 수 있습니다. 사설 IP나 사내 장비 주소를 찾는 도구는 아닙니다.

확인 기준: 회사 VPN, 프록시, 모바일 테더링을 사용하면 실제 기기 위치가 아니라 해당 네트워크의 출구 IP가 표시될 수 있습니다. IPv4와 IPv6 허용 규칙이 다를 수 있으므로 요청 대상 시스템이 요구하는 주소 형식을 먼저 확인하세요.

개인정보 처리: 공인 IP 확인을 위해 이 페이지를 열거나 다시 조회할 때 브라우저가 화면 위쪽 '조회 서비스'에 적힌 외부 서비스(ipify, Cloudflare, 필요 시 country.is)로 직접 요청을 보냅니다. 각 서비스의 로그 보관 여부는 해당 서비스 정책을 따르며, 이 사이트 서버에는 조회 결과가 저장되지 않습니다. 결과를 복사해 메신저나 티켓에 남길 때는 조직의 보안 정책과 보관 기간을 따르세요.
