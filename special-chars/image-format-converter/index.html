💡 무료 이미지 확장자 포맷 변환 가이드

이미지 확장자별 변환은 어떤 차이가 있나요?

입력은 JPG·PNG·WebP·GIF·BMP·SVG, 출력은 JPG·PNG·WebP를 지원합니다. GIF·BMP·SVG는 출력 포맷으로 선택할 수 없습니다.

  • JPG (JPEG): 풍경 사진, 극사실주의 스틸컷 등 색감이 다양한 객체에 적합합니다. 용량이 가벼운 손실 압축 방식을 사용합니다.
  • PNG: 로고, 글씨가 많은 스크린샷과 투명 배경이 필요한 이미지에 적합한 무손실 출력 포맷입니다. 다만 원본을 캔버스로 다시 그리는 과정에서 일부 메타데이터는 유지되지 않을 수 있습니다.
  • WebP: 사진과 투명 이미지를 모두 지원하는 웹용 포맷입니다. 파일에 따라 JPG·PNG보다 작아질 수 있지만 항상 용량이 줄어드는 것은 아닙니다.
GIF 애니메이션과 SVG 벡터 정보도 유지되나요?

아닙니다. 이 도구는 브라우저 캔버스에 이미지를 그린 뒤 다시 인코딩합니다. 애니메이션 GIF는 한 장의 정지 프레임으로 변환되고, SVG는 현재 표시 크기의 픽셀 이미지로 래스터화되어 벡터 확대 특성을 잃습니다. 해당 파일을 선택하면 변환 전에 경고가 표시됩니다.

품질 설정 등은 어떻게 진행하나요?
  • JPG / WebP: 품질 수치가 높을수록 압축 손실은 줄어드는 경향이 있지만 파일 크기 변화는 이미지마다 다릅니다. 여러 값을 비교하고 결과 패널의 실제 용량과 화면 품질을 함께 확인하세요.
  • PNG: 출력 인코딩이 무손실이라 품질 슬라이더를 사용하지 않습니다. 다만 원본을 캔버스로 다시 그리므로 원본의 메타데이터·색상 프로필 등이 그대로 유지된다는 뜻은 아닙니다.
업로드된 저의 개인 사진은 서버에 기록되나요?

선택한 이미지의 읽기와 변환은 현재 브라우저 안에서 진행되며 변환을 위해 파일을 서버에 업로드하지 않습니다. 다만 공용 기기에서는 다운로드된 결과 파일과 브라우저 기록을 직접 관리해 주세요.
