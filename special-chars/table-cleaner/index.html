사용 방법과 데이터 처리 기준

엑셀 표는 어떻게 가져오나요?

엑셀, 구글 스프레드시트 또는 다른 표 프로그램에서 필요한 셀 범위를 복사한 뒤 원본 입력 칸에 붙여넣으세요. 보통 열 사이는 탭으로 전달되므로 ‘자동 감지’가 바로 표 구조를 찾습니다. CSV·TSV·TXT 파일은 ‘CSV·TSV 열기’로 불러올 수 있지만 XLSX 파일 자체는 읽지 않습니다. 여러 시트가 있다면 시트별로 필요한 범위를 복사해 사용하세요.

각 정리 옵션은 원본을 어떻게 바꾸나요?

‘셀 앞뒤 공백’은 값의 시작과 끝에 붙은 공백만 제거합니다. ‘연속 공백 합치기’는 셀 안의 줄바꿈과 여러 칸 공백을 한 칸으로 바꾸므로 주소나 코드처럼 공백이 중요한 자료에서는 끄는 것이 안전합니다. 빈 행·열은 모든 셀이 비어 있을 때만 삭제하며, 중복 행은 정리 후 모든 셀 값이 같은 두 번째 행부터 제거합니다.

CSV, TSV, JSON, 마크다운은 언제 쓰나요?

CSV는 일반적인 데이터 전달과 업로드에, TSV는 변환 결과를 다시 엑셀에 붙여넣을 때 편합니다. JSON은 첫 행을 제목으로 사용해 객체 배열을 만들며, 같은 제목이 반복되면 뒤에 번호를 붙입니다. 마크다운은 문서와 이슈에 붙일 수 있는 표 문법으로 변환합니다. CSV 파일을 국내 엑셀에서 바로 열 예정이라면 ‘UTF-8 BOM’을 유지하는 편이 한글 깨짐을 줄이는 데 도움이 됩니다.

검수할 때 주의할 점이 있나요?

자동 구분자 감지가 숫자의 쉼표나 본문의 세로선을 열 구분자로 오인할 수 있으므로 미리보기의 행·열 수를 먼저 확인하세요. 따옴표로 묶은 CSV 셀의 쉼표와 줄바꿈은 유지되지만, 닫히지 않은 따옴표가 있으면 변환을 중단합니다. 외부에서 받은 CSV에 =, +, -, @로 시작하는 값이 있다면 스프레드시트에서 수식으로 실행될 가능성이 있으므로 열기 전에 출처와 값을 확인해야 합니다.

자료가 서버에 올라가나요?

붙여넣은 표, 불러온 파일, 정리 결과는 모두 현재 브라우저 탭에서만 처리하며 서버나 브라우저 저장소에 보관하지 않습니다. 파일 저장과 복사를 누르면 결과가 기기 다운로드 폴더 또는 운영체제 클립보드로 이동합니다. 민감한 고객·인사 자료를 처리한 뒤에는 입력값과 클립보드 기록을 지워 주세요.

지원 범위: 구분자로 나뉜 2차원 텍스트 데이터를 처리합니다. 수식 계산, 셀 색상, 병합, 필터, 숨김 행, 날짜·통화 표시 형식처럼 스프레드시트 서식은 가져오지 않으며 보이는 셀 값만 사용합니다.

데이터 처리: 표는 현재 탭의 메모리에서만 파싱하고 정리하며 서버로 전송하거나 자동 저장하지 않습니다. 저장한 파일은 변환 결과이므로 원본 파일과 행·열 수를 대조한 뒤 업무 시스템에 업로드하세요.
