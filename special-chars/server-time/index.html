💡 정밀 시계와 응답속도 측정 가이드

이 시계는 어떤 시각을 표시하나요?

기본은 브라우저가 실행 중인 기기의 시스템 시계입니다. 페이지를 열면 이 사이트(teemozipsa.com) 서버가 응답에 붙이는 표준 시각(HTTP Date 헤더)과 기기 시계를 비교해 오차를 추정하고, '측정한 오차로 시계 보정'이 켜져 있으면 그만큼 더하거나 빼서 보여 줍니다. 예를 들어 "내 기기 시계가 약 0.8초 빠릅니다 (±0.1초)"라면 화면 시계는 기기보다 0.8초 늦게 표시됩니다.

대상 서비스의 기준 시각과의 차이를 따로 알고 있다면 '추가 수동 보정'에 밀리초 단위로 더할 수 있습니다. 보정값과 목표 시각은 이 브라우저에만 저장됩니다.

오차는 어떻게 측정하고, 얼마나 정확한가요?

HTTP Date 헤더는 초 단위까지만 기록됩니다. 그래서 이 도구는 이 사이트에 작은 HEAD 요청을 여러 번 보내되, 서버 시각의 초가 바뀌는 순간 근처에 요청이 도착하도록 보내는 시점을 조금씩 옮깁니다. 각 응답은 "서버 시각이 이 범위 안에 있었다"는 조건을 주고, 조건을 겹쳐 가면 오차 범위가 좁아집니다. 보통 6~10회, 수 초 안에 끝나며 남는 불확실성(±)은 대략 네트워크 왕복 시간의 절반입니다.

측정 기준은 이 사이트를 제공하는 서버(CDN)의 시계입니다. 이런 서버는 보통 인터넷 표준시에 맞춰져 있어 기기 시계 점검에는 충분하지만, 예매·수강신청 사이트의 서버 시각을 읽은 값은 아닙니다. 다른 사이트의 응답 헤더는 브라우저 보안 정책(CORS) 때문에 읽을 수 없고, 이 도구는 외부 프록시를 쓰지 않습니다. 또한 대기열 시스템이나 서버 처리 순서 때문에 정확한 시각에 누른다고 접수가 보장되지는 않습니다.

목표 시각 카운트다운과 예고음은 언제 울리나요?

오픈·마감 시각을 넣으면 보정된 시계 기준으로 남은 시간을 0.1초 단위로 보여 줍니다. 이미 지난 시각이면 다음 날 같은 시각으로 계산합니다. '목표 N초 전부터'를 켜면 선택한 시각의 N초 전부터 매초 짧은 예고음이, 정각에는 긴 알림음이 울립니다. 예전처럼 매분 정각마다 울리지 않고, 정한 목표 시각에만 울립니다.

알림음은 체크박스를 켤 때 브라우저 오디오 시계에 미리 예약되므로 다른 탭을 보고 있어도 제시간에 울립니다. 다만 브라우저 자동 재생 정책 때문에 체크박스를 직접 눌러야 소리가 켜지고, 기기가 절전 상태에 들어가면 울리지 않을 수 있습니다. 중요한 일정은 휴대폰 알람도 함께 쓰세요.

웹사이트 응답속도는 어떻게 측정하나요?

입력한 주소로 가벼운 HEAD 요청을 보냅니다. 첫 요청은 DNS 조회와 보안 연결(TLS) 준비 시간이 섞여 크게 나오므로 결과에서 빼고, 이어지는 5회의 중앙값과 최솟값을 보여 줍니다. 빠른 버튼은 주소만 채우며, '응답속도 측정'을 눌러야 요청이 전송됩니다.

이 값은 네트워크 왕복 시간과 서버 처리 시간이 합쳐진 대략적인 대기 시간이며, 전용 핑(ping)이나 서버 시계 차이를 뜻하지 않습니다. 쿠키는 보내지 않지만 대상 사이트에는 실제 요청이 전달되므로 사내 전용 주소나 민감한 쿼리 문자열은 입력하지 마세요. 브라우저 보안 정책이나 사이트 설정에 따라 측정이 실패할 수 있습니다.
