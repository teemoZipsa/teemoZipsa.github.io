양수는 시계를 빠르게, 음수는 느리게 표시합니다. 보정 범위는 ±60초이며 알림에도 적용됩니다.

💡 정밀 로컬 시계와 응답속도 측정 가이드

이 시계는 어떤 시간을 표시하나요?

화면의 시각은 브라우저가 실행 중인 기기의 시스템 시계를 밀리초 단위로 표시한 값입니다. 운영체제의 자동 날짜·시간 동기화를 켜 두면 가장 유용하며, 이 페이지가 별도의 표준시 서버와 동기화하는 것은 아닙니다.

기기 시계와 알고 있는 기준시 사이에 차이가 있다면 수동 보정값을 밀리초 단위로 입력할 수 있습니다. 밀리초 숫자가 자세히 보인다고 해서 기기 시계 자체의 정확도가 보장되는 것은 아닙니다.

웹사이트 응답속도는 어떻게 측정하나요?

입력한 URL로 가벼운 HEAD 요청을 3회 보내고, 브라우저가 각 응답을 받기까지의 경과 시간을 측정해 최솟값·평균값·최댓값을 보여줍니다.

이 값에는 DNS 조회, 연결, TLS 협상, 네트워크 상태와 서버 처리 시간이 함께 포함될 수 있습니다. 전용 네트워크 핑(ping)이나 서버 시계 차이를 뜻하지 않으며, 현재 브라우저 환경의 참고값입니다.

왜 서버 시간을 직접 표시하지 않나요?

다른 출처의 웹사이트는 브라우저의 CORS 정책 때문에 응답 헤더를 읽을 수 없는 경우가 많습니다. HTTP Date 헤더도 일반적으로 1초 단위이며 실제 서비스의 접수 기준 시각을 보장하지 않으므로, 밀리초 정밀 서버 시계로 사용할 수 없습니다.

이 도구는 외부 CORS 프록시를 사용하거나 서버 시각을 추정하지 않습니다. 응답속도 측정 요청에는 쿠키를 보내지 않지만, 대상 사이트에는 일반적인 네트워크 요청이 전달됩니다. 브라우저 정책, 혼합 콘텐츠 차단 또는 사이트 설정에 따라 측정이 실패할 수 있습니다.

틱 소리와 정각 알림은 언제 울리나요?

‘매초 틱 소리’는 표시 시계의 초가 바뀔 때 짧게 울립니다. 정각 알림을 켜면 58초와 59초에 서로 다른 예고음이 나고, 00초에 정각 알림과 화면 효과가 실행됩니다.

브라우저의 자동 재생 정책 때문에 페이지를 연 뒤 한 번은 클릭하거나 키를 눌러야 소리가 활성화될 수 있습니다. 수동 시계 보정값은 이 알림 시점에도 적용됩니다.

알림은 페이지가 화면에 표시되고 브라우저가 정상적으로 갱신할 때 가장 잘 동작합니다. 백그라운드 탭, 기기 절전, 메인 스레드 지연에서는 58·59·00초 프레임을 건너뛰어 소리를 놓칠 수 있으므로 중요한 접수 시각을 이 알림에만 의존하지 마세요.
