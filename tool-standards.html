도구 제작·검증 기준

도구 수만 늘리지 않고, 새로운 도구 하나가 사용자의 시간을 실제로 줄이고 사이트의 신뢰를 더하도록 관리하는 기준입니다.

티모집사 툴즈는 설치와 로그인 없이 바로 쓰는 직장인용 브라우저 업무 도구를 만듭니다. 아이디어를 구현했다는 이유만으로 검색에 공개하지 않습니다. 해결하려는 업무, 처리 범위, 예외 상황, 개인정보 흐름과 검증 결과를 확인한 도구만 대표 목록과 사이트맵에 포함합니다.

공개 단계

1

문제 정의

사용자, 업무 상황과 완료 조건을 한 문장으로 정합니다.

2

실험 도구

기능과 예외를 구현합니다. 검증 전에는 검색 대상에 넣지 않습니다.

3

검증

계산값, 파일 처리, 접근성과 주요 브라우저 동작을 확인합니다.

4

업무 도구

사용법과 한계를 갖춘 뒤 카탈로그와 사이트맵에 공개합니다.

중요: 새 도구를 추가하는 것 자체가 품질을 높이지는 않습니다. 아래 기준을 통과한 도구가 늘어날 때 해결 가능한 업무와 검증 근거도 함께 늘어납니다.

도구 하나에 필요한 정보

사용자에게 보이는 정보

  • 해결하는 업무와 적합한 사용 상황
  • 입력값과 결과를 이해할 수 있는 예시
  • 계산 기준 또는 변환 방식
  • 지원 범위, 오차와 예외 상황
  • 파일 업로드·저장·외부 통신 여부
  • 관련 도구와 정정 제보 경로

게시 전 내부 검증

  • 정상값·경계값·잘못된 입력 테스트
  • 계산 도구의 독립된 기대값 비교
  • 키보드 조작과 자동 접근성 검사
  • Chromium·Firefox·WebKit 렌더링
  • 모바일 화면과 터치 영역 확인
  • 제3자 코드 버전·무결성·라이선스 확인

브라우저 로컬 우선 원칙

텍스트 계산, 수식 계산, 이미지 변환과 PDF 편집은 가능한 한 사용자의 브라우저 안에서 처리합니다. 외부 서버가 필요한 기능은 목적과 전송 범위를 해당 페이지 및 개인정보처리방침에 표시합니다. “로컬 처리”는 선택한 입력을 앱 서버로 보내지 않는다는 뜻이며, 브라우저 기록이나 사용자가 내려받은 결과 파일까지 자동으로 삭제한다는 뜻은 아닙니다.

계산과 정보의 정확성

  • 기초 산술과 변환식은 별도의 테스트 케이스로 기대값을 비교합니다.
  • 공휴일·요율·법령처럼 달라질 수 있는 값은 기준 지역과 확인일을 표시합니다.
  • 반올림, 절사, 시작일 포함 여부처럼 결과를 바꾸는 규칙을 숨기지 않습니다.
  • 의료·금융·법률 판단을 대신하지 않으며, 중요한 결정은 공식 문서와 전문가 확인을 우선합니다.

검색 공개와 사이트맵

INDEX POLICY

실험 중이거나 다른 도구와 기능·설명이 겹치는 페이지는 noindex 상태로 운영하고 홈페이지 업무 카탈로그에도 노출하지 않습니다. 기능, 고유한 업무 맥락, 안내 콘텐츠와 검증이 준비된 페이지에 한해 카탈로그·검색 색인·사이트맵에 함께 등록합니다. 도구를 삭제하기 위한 절차가 아니라 준비되지 않은 페이지가 사이트 전체의 품질 신호를 희석하지 않게 하는 절차입니다.

광고 원칙

광고는 도구 입력, 실행 버튼, 다운로드 링크 또는 결과처럼 보이지 않게 분리합니다. 빈 광고 자리와 클릭 유도 문구를 사용하지 않으며, 도구를 완료하는 흐름을 가리거나 오작동을 유발하는 위치에는 배치하지 않습니다. 광고 승인 여부와 무관하게 이 기준을 유지합니다.

수정과 확인일

오류가 결과에 영향을 줄수록 먼저 수정합니다. 재현 가능한 입력값이나 공식 출처와 함께 문의 및 제보로 알려주시면 확인에 도움이 됩니다.
